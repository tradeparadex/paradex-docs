## v1.166.2

<ChangelogTags tags={["API", "UI"]} />

#### API

* Fixed Hyperlane deposits and withdrawals staying pending in transfer history.
* RFQs that would exceed a position limit are now refused at creation instead of failing after execution.
* Referral links shared before a referral code rename keep crediting the referrer.
* SBE feeds no longer report wrapped negative values for very large balances and volumes.

#### UI

* `RFQ builder` and `quote card` now show the order's `USD` notional.
* Links you share from Paradex, now credit you with the signups they bring.
* Positions and Trade History now group option strategies.
