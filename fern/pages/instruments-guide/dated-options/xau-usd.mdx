The reference configuration for the XAU Dated Options contract:

| Parameter | Value |
|-----------|-------|
| Product type | Dated European Option |
| Symbol format | XAU-USD-{Expiry}-{Strike}-{Type} |
| Base currency | XAU |
| Quote currency | USD |
| Settlement currency | USDC |
| Price tick size | 0.01 USD |
| Order size increment | 0.1 XAU |
| Minimum order value | 20 USD |
| Maximum order size | 100 XAU |
| Maximum open orders | 150 |
| Position limit | 1,000 XAU |
| Spot band factor | 30% |
| IV band factor | 30% |
