Here you'll find all the documentation you need to get up and running with the Paradex WebSocket API.

<Warning title="SBE required for public channels as of 21 September 2026">
As of 21 September 2026, Paradex requires [Simple Binary Encoding (SBE)](/ws/general-information/binary-encoding-sbe) for public channel payloads. JSON is no longer served for public channels. Append `?sbeSchemaId=1&sbeSchemaVersion=1` to the WebSocket URL and decode incoming binary frames, or use the Python SDK (`paradex-py` v0.7.0 or later) with `sbe_enabled=True`. JSON-RPC control messages and private channel payloads are unchanged.
</Warning>
