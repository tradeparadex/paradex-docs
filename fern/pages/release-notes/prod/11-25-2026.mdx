## v1.173.5

<ChangelogTags tags={["UI", "API"]} />

#### UI

* `Portfolio margin` estimates now include the margin relief for resting `MMP` orders.
* `Deposit`, `Withdraw` and `Transfer` show their frame at once while loading and open faster after sign in.

#### API

* Cancel orders by base asset is now supported on the API and WebSocket endpoints.
* The API reference now documents `session keys` and `passkeys`.
