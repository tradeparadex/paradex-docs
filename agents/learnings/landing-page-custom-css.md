# Landing page and custom CSS/JS dependencies

## What the home page depends on

`fern/pages/what-is-paradex.mdx` previously used `layout: custom` + `lp-*` classes defined in `fern/assets/styles.css` and animations driven by `fern/assets/home-page.js`. Without `css:`/`js:` in `docs.yml` the page rendered as unstyled raw content.

As of PR #1431 it is rebuilt with standard components only (`layout: page`, frontmatter `title`/`subtitle`, `<Button>`, `<CardGroup>`/`<Card>` with `fa-solid fa-*` icons), so it renders correctly with or without custom CSS/JS.

## Remaining custom CSS/JS consumers

- `fern/assets/styles.css`: mostly `lp-*` (landing page, now unused) plus site-wide overrides (`.fern-*` selectors) and `.cyan-cards` used by `fern/pages/developer-portal/general-information/api-quick-start.mdx`. Removing `css:` entirely would need the `cyan-cards` usage replaced first.
- `js:` scripts in `docs.yml`: cookie-consent banner + Google Consent Mode (`consent-defaults.js`, `vendor-cookieconsent.bundle.js`, `cookie-consent.js` — compliance-relevant, generated by `scripts/sync-vendor-assets.js` on `yarn install`), tracking pixel (`dist/add-pixel.js`), `tvl-limit.js`, `home-page.js`.
- `fern/assets/wallet-connect.js` exists but is not referenced by `docs.yml` — appears unused.

## Conventions observed

- Page headers come from frontmatter `title`/`subtitle`; body does not repeat an `# h1`.
- Overview/landing-style pages use `layout: reference` or `layout: page` (no sidebar) with `hide-toc: true`.
- Card icons use `fa-solid fa-*` strings.
