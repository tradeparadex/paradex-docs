Here you'll find all the documentation you need to get up and running with the Paradex WebSocket API.

<Warning title="SBE required for public channels as of 21 September 2026">
As of 21 September 2026, Paradex requires Simple Binary Encoding (SBE) for public channel payloads. See [Binary Encoding (SBE)](/ws/general-information/binary-encoding-sbe) for details on how to enable it.
</Warning>
