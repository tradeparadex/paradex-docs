The reference configuration for the CRCL Dated Options contract:

| Parameter | Value |
|-----------|-------|
| Product type | Dated European Option |
| Symbol format | CRCL-USD-{Expiry}-{Strike}-{Type} |
| Base currency | CRCL |
| Quote currency | USD |
| Settlement currency | USDC |
| Price tick size | 0.001 USD |
| Order size increment | 1 CRCL |
| Minimum order value | 20 USD |
| Maximum order size | 5,000 CRCL |
| Maximum open orders | 150 |
| Position limit | 50,000 CRCL |
| Spot band factor | 50% |
| IV band factor | 50% |
