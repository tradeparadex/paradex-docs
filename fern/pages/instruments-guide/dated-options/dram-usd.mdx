The reference configuration for the DRAM Dated Options contract:

| Parameter | Value |
|-----------|-------|
| Product type | Dated European Option |
| Symbol format | DRAM-USD-{Expiry}-{Strike}-{Type} |
| Base currency | DRAM |
| Quote currency | USD |
| Settlement currency | USDC |
| Price tick size | 0.0005 USD |
| Order size increment | 1 DRAM |
| Minimum order value | 20 USD |
| Maximum order size | 5,000 DRAM |
| Maximum open orders | 150 |
| Position limit | 50,000 DRAM |
| Spot band factor | 50% |
| IV band factor | 50% |
