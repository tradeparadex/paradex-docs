## v1.171.3

<ChangelogTags tags={["UI", "API"]} />

#### UI

* Unfunded new accounts see a funding notice in RFQ instead of an error.
* Charts, tables and cards in the Dime Terminal chat match the rest of the terminal. The payoff chart no longer has a "Load into order builder" button.

#### API

* RFQ endpoints now return `NOT_ONBOARDED` for an account that is still onboarding.
* Derive blocks with a leg priced at zero now appear on the options tape.
* Selling your last ecosystem NFT now removes its fee-tier boost after the next update.
