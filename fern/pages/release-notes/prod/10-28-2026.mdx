## v1.169.2

<ChangelogTags tags={["UI", "API"]} />

#### UI

* Re-designed and more intuitive `Order Builder` for `Market/Limit/RFQ` orders.
* Switching to isolated margin with `TWAP` selected now falls back to a market order.
* `Isolated margin` accounts can no longer be created or topped up.
* You can now `bulk import and export saved Paradex addresses` in the `Transfer` address book as CSV.
* Fixed saved address book names with angle brackets showing blank or garbled.
* Signing up with a smart contract wallet now explains that a regular wallet is needed.
* `Transfer` now explains when the address is not a `Paradex` account and where it belongs.

#### API

* Wallets with no balance can now onboard and deposit.
