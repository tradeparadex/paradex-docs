# Release notes and Vale

## Gotchas

- Vale.Spelling flags "underlyings" (plural noun). Write "underlying assets" instead of adding it to the vocabulary.
- Vale is not installed locally; read the failure from CI with `gh run view <run-id> --log-failed` and grep for `error`.
- Past-tense "onboarded" is also flagged (see `account-deployment.md`).
