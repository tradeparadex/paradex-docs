The reference configuration for the META Dated Options contract:

| Parameter | Value |
|-----------|-------|
| Product type | Dated European Option |
| Symbol format | META-USD-{Expiry}-{Strike}-{Type} |
| Base currency | META |
| Quote currency | USD |
| Settlement currency | USDC |
| Price tick size | 0.01 USD |
| Order size increment | 0.1 META |
| Minimum order value | 20 USD |
| Maximum order size | 500 META |
| Maximum open orders | 150 |
| Position limit | 5,000 META |
| Spot band factor | 50% |
| IV band factor | 50% |
