## Token Overview

| Property | Value |
|---|---|
| Name | DIME |
| Ticker | \$DIME |
| Total supply | 1,000,000,000 \$DIME |
| Decimals | 18 |
| Networks | Ethereum, Paradex Chain |

\$DIME is natively issued on Ethereum and bridged to Paradex Chain, where it is used for staking, fee payments, and trading on the [DIME-USD spot market](/trading/instruments-guide/spot/dime-usd). See [DIME Utility](/dime/dime-utility) for how \$DIME is used across Paradex.
